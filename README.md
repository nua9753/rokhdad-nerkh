# رخداد نرخ

افزونه‌ی وردپرس قیمت لحظه‌ای طلا، سکه، ارز و ارز دیجیتال برای گسترش نیوز، با داده‌ی BrsApi.

## نصب
فایل `rokhdad-nerkh.zip` را از آخرین [Release](../../releases/latest) بگیرید و در «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.

## به‌روزرسانی
از نسخه‌ی ۰٫۷ به بعد، نسخه‌های تازه مثل افزونه‌های مخزن وردپرس در «پیشخوان ← به‌روزرسانی‌ها» دیده می‌شوند. برای نصب خودکار، در فهرست افزونه‌ها «فعال‌سازی به‌روزرسانی خودکار» را برای رخداد نرخ روشن کنید.

## انتشار نسخه‌ی تازه
1. شماره‌ی `Version` و `NRY_VER` در `rokhdad-nerkh.php` را بالا ببرید و تغییرات را در `release-notes.md` بنویسید.
2. روی `main` بفرستید.
3. GitHub Actions فایل zip را می‌سازد و Release همان نسخه را منتشر می‌کند. اگر Release آن نسخه از قبل باشد، کاری نمی‌کند.
